# BrickEmuPy curation handoff

Brief for a deep curation round over every game in [BrickEmuPy](https://github.com/azya52/BrickEmuPy) (CC0), the LCD-game emulator whose cores we're porting into this app (`source/BrickCores/`). Everything technical is already extracted from its `.brick` configs, ROMs and face SVGs; what's missing is the catalogue information below. Generated by `CONVERT_ROM/tmp/make_handoff.py` - re-run it after curating to refresh the tables.

Results go into `CONVERT_ROM/brick_games.json` (one entry per `.brick`, keyed by `brick`), which `CONVERT_ROM/brick_import.py` reads. A game is only imported once its `name`, `manufacturer` and `date` are filled in and its core is ported.

## What we need for each game

| Field | `brick_games.json` key | Notes |
|---|---|---|
| Display name | `name` | Official title as sold. Conventions below. |
| Manufacturer / brand | `manufacturer` | Pick an existing menu group or propose a new one (see Decisions). |
| Release date | `date` | `YYYY-MM-DD`; `YYYY-01-01` when only the year is known; leave a note when it's a guess. |
| Region / variant | (part of `name`) | Only when two configs need telling apart, e.g. `(Japan)`, `(International)`, `(Spanish)`. |
| Model / catalogue no. | `model` (new, optional) | E.g. Popy `CO-02`, Spica `SH-002B`, brick game `E-23`. Useful for search and disambiguation. |
| Clone of | `clone_of` (new, optional) | Another `brick` in this list it's a variant/reskin of (we file clones under their ultimate origin, as with Burger Bard). |
| Physical button labels | `keys` (override) | Only if the auto-mapped controls (column below) feel wrong - give `{"btnX": "A"}` style overrides. Key names: A B X Y L R PLUS MINUS UP DOWN LEFT RIGHT; `+` = chord, `|` = either. |
| Notes / sources | `notes`, `sources` (new, optional) | Dump-quality warnings, where each fact came from (URLs). |

### Naming conventions (from the existing library)

- Title only - no maker prefix in the name (the menu groups by manufacturer): `Pengo`, not `Bandai Pengo`.
- Keep official subtitles and punctuation: `Mori de Hakken! Tamagotchi`, `Dr. Slump Arale: Ncha! Bycha`-style.
- Japanese titles: the official romanization/English title if one exists, otherwise a romanization of the Japanese.
- Series prefixes the maker printed on the unit (Popy's "Animest", Gakken's "LCD Card Game") - decide once for the series (Decisions).
- Variants of the same game: `Title (Variant)`, e.g. `Tamagotchi (Gen. 1, Japan)`, `Digital Monster (Spanish)`.

## Decisions needed (global)

1. **New manufacturer groups.** Existing: Nintendo, Tronica, Elektronika, Tiger, Konami, Nelsonic, V-Tech, Bandai, Epoch, Nikko, Tandy, David & John, McDonald's, Burger Bard. Candidates from this list: Popy (a Bandai brand - own group or under Bandai?), Gakken, Spica, Hiro, Edla, Koto Laboratory, Apollo, Hartung (Formel 1, with Epoch), and the many unbranded Chinese brick games/keychains/pets (one "Brick Game"/"Unbranded" group, or by OEM/model?).
2. **McDonald's Tetris Nugget (2023).** The McDonald's group is wired to the LCDonald engine (`GW_rom::is_lcdonald_family`), so this real-ROM game can't simply join it - new group, or rework that check?
3. **Experimental gating.** Assume every new core's games sit behind Experimental Games, like the E0C6200 set?
4. **Questionable dumps.** BrickEmuPy flags Tamagotchi Connection V3 and Tamagotchi Mini 2017 as "high probability of errors in the dump" - include, include with a note, or skip?
5. **Same-ROM configs.** Some `.brick`s share one ROM with different settings (table below) - one entry each, or one per ROM?
6. **Series names.** Keep or drop "Animest" (Popy), "LCD Card Game" (Gakken), "Game Watch" (Nelsonic)?

## Already-packed E0C6200 games: open checks

These are in the pack already (`games_path_rgds.py`, `GNW_LIST.md`), but a few facts were guesses:

- **Umi de Hakken!! Tamagotchi** (`TAMAUMI`) - release date unconfirmed (packed as 1998-01-01).
- **Digital Monster (Spanish)** (`DIGIMONES`) - release date and exact title unconfirmed (packed as 1997-01-01).
- **Tamagotchi (Gen. 1, Japan)** (`TAMAJ`) - packed as 1996-01-01; the Japanese launch was November 1996, worth confirming.
- Names of all 17 were chosen without a dedicated research pass - worth a sanity check against official naming.
